# Sebastian Cristea — Portfolio IT & Ciberseguridad

Portfolio personal de **Sebastian Cristea**, orientado a la administración de sistemas, redes y ciberseguridad. La web reúne proyectos prácticos, laboratorios propios y writeups de máquinas y retos de seguridad.

🌐 **Web publicada:** [https://seseby.github.io/](https://seseby.github.io/)

## Sobre el proyecto

Este sitio funciona como presentación profesional y punto de acceso a mis proyectos técnicos. Está diseñado con una estética inspirada en terminales y herramientas de administración, y se publica como sitio estático mediante GitHub Pages.

## Contenido

- **Sobre mí:** perfil e intereses profesionales.

- **Proyectos destacados:** acceso directo a mis repositorios de laboratorios y writeups.
- **Contacto:** enlaces al correo profesional, LinkedIn y GitHub.

- **[Writeups de ciberseguridad](https://github.com/seseby/Writeups):** documentación de laboratorios de pentesting, enumeración, análisis de vulnerabilidades y resolución de retos prácticos.

## Ejecutar en local

No necesita instalación de dependencias ni proceso de compilación.

1. Clona el repositorio:

   ```bash
   git clone https://github.com/seseby/seseby.github.io.git
   ```

2. Entra en la carpeta:

   ```bash
   cd seseby.github.io
   ```

3. Abre `index.html` en el navegador. Para una experiencia de desarrollo más cómoda, puedes utilizar la extensión **Live Server** de Visual Studio Code.

## Publicar con GitHub Pages

1. Sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz del repositorio `seseby.github.io`.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)` y guarda los cambios.
5. Espera a que termine el despliegue y visita [https://seseby.github.io/](https://seseby.github.io/).

Los cambios realizados en la rama publicada se desplegarán automáticamente cuando GitHub Pages termine de procesarlos.
