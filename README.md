# Portfolio — Sebastian Cristea

Archivos para publicar en GitHub Pages:
- `index.html`: estructura y contenido.
- `style.css`: estilos de la página.
- `script.js`: animaciones e interacciones del lado del navegador.

Las fuentes JetBrains Mono y Outfit se cargan desde Google Fonts. El avatar y el favicon que están incrustados en el HTML no necesitan archivos separados.

**Nota sobre la suscripción:** GitHub Pages no ejecuta código de servidor. El formulario muestra un aviso hasta que se conecte a un servicio externo de suscripción. El código de analítica de Cloudflare se ha omitido porque no es necesario para mostrar la web.
